# 团队试用指引

网页侧栏的「使用指引」提供同一流程的简版。

## 出题与审阅

1. 在题目页新建或导入私有草稿，填写名称、标签、负责人。在出版区选择语言和已发布模板，题面、文档题解、Beamer 分别保存。
2. 在程序区保存主标程、校验器、正确/错误解及预期判定；准备数据、答案、生成计划和分组后运行相应任务。检查矩阵和日志，修改依赖后重新验收。
3. 在组织区保存不可变修订并提交审核。审题人选择具体修订，核对差异、固定程序、数据和验收报告，评论后批准或要求修改。负责人核对有效验收后冻结。
4. 比赛只选择已冻结修订，明确题号、题册和讲解顺序、语言与模板，保存并冻结比赛。按材料分别构建、预览、发布或导出，缺稿需补齐或明确选择子集。

开发环境可搜索「分组」找到既有示例；「ProblemForge 三题示例赛」保留冻结比赛和三类成功 PDF。任务中心能按题目/比赛、用途和时间查询已有验收，复用未改变依赖的结果，不必为了走查重新执行 Judge/TeX。原生 FULL 包用于源码交接；其他用途仅导出对应材料，导入报告中的阻塞项必须处理，新题仍需重新验收。

## 编辑与恢复

文稿、程序、比赛编排和模板显示保存中、未保存、已保存版本及持续失败提示。请求发出后继续输入的修改仍为未保存状态；服务端 CAS 冲突不会覆盖本地输入。点击「下载本地草稿」可查看完整 JSON、下载或复制，包含本地内容和基准版本。浏览器限制文件下载时使用复制或在文本框全选复制。导出仅保存在浏览器内存，关闭窗口后需要重新导出。

先取回草稿，再重新载入服务端内容逐项合并、粘贴和保存；没有自动导入或覆盖服务端功能。JSON 含私有正文或源码，应按题目权限保管。登录失效不会移除当前编辑器，先导出，再重新登录。

切换语言或文稿会保留本页已经载入的编辑；功能区首次进入才加载，切回保留状态。离开题目/编辑页、退出登录及刷新有未保存提示。浏览器标签页会按账号和题目记住语言、文稿、功能区、程序选择；恢复的是导航位置，**不是未保存正文**。返回列表保留搜索地址，「继续上次题目」返回最近工作区。浏览器存储不可用时仍可正常使用，不跨设备同步导航。

## 管理员

管理员独占模板维护：复制草稿 → 编辑保存 → 沙箱验证 → 检查真实 PDF → 发布，已发布版本不原地修改。账号创建、启停、重置和会话管理见 [ACCOUNTS](ACCOUNTS.md)；历史查询见 [HISTORY](HISTORY.md)；升级和备份见 [DEPLOYMENT](DEPLOYMENT.md)。
