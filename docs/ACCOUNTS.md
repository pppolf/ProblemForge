# 协会账号与本地权限

工作台只接受协会官网的**账号或邮箱 + 密码**。后端向 `https://www.cwnupaa.com/api/user/external/login` 发送 `appKey`、`loginType: "password"`、`account`、`credential`，再建立本系统的会话。未接入验证码登录、短信或本地密码回退。

## 配置

在主目录原 `.env` 中填写：

```dotenv
ASSOCIATION_APP_KEY=
```

当前留空，登录页明确提示尚未配置。取得真实 APPKEY 后填入并重启原 API（或确认无活动任务后重启原 `pnpm dev`），继续使用 `http://localhost:5180` / API 3100。密钥只由后端使用，不加 `VITE_` 前缀、不写到前端或 Git。生产 Compose 仅把它传给 API，Worker 和执行沙箱不需要它。

官网返回业务 code=200 且用户身份完整才允许登录。请求使用 HTTPS、8 秒超时、不跟随重定向、最多读取 32 KiB 响应；网络失败、异常响应和缺少配置明确报错。账号可去除首尾空白，密码原样转发。密码、APPKEY、远端原始响应不写数据库、业务审计或日志。本地 8 次/10 分钟登录限流、Origin、CSRF、HttpOnly / SameSite=Strict Cookie 继续有效。

## 新用户与旧账号

协会 `userId` 作为精确的十进制字符串保存，兼容 Java Long，避免 JavaScript 数字精度导致身份混淆。同一 userId 使用账号或邮箱登录均对应同一本地用户。首次登录自动建立 **USER 普通用户**；协会接口不提供本系统角色，不能自动取得管理员权限。姓名、账号名和邮箱在后续登录时同步，不使用姓名或邮箱自动合并身份，也不保存学号或真实姓名字段。

2026-10-02 按用户要求清理后，原开发库只保留 `admin-f054@problemforge.local` 一个系统管理员（ADMIN）；其余用户、题目、比赛及全部旧会话已删除，模板和编译配置保留。该管理员尚未绑定协会身份。要继承其权限，操作者须先向协会核对其 **userId（不是学号、账号名或邮箱）**，然后在主目录显式绑定：

```powershell
pnpm user:link --email admin-f054@problemforge.local --user-id 协会userId
```

绑定保留原本地用户 ID、角色和成员关系，清除其旧本地密码与重置凭据并撤销旧会话。已经绑定其他身份或该协会 ID 已被另一个本地用户使用时拒绝覆盖/合并。同邮箱发生冲突时登录返回 ACCOUNT_LINK_REQUIRED，先绑定原账号再登录，不自行把旧管理员归给新用户。旧 `.local/bootstrap-admin.txt` / `manual-test-access.txt` 中的本地密码已不能登录；本次数据清理已撤销所有旧会话。

全新部署的首个管理员，在其首次登录前初始化：

```powershell
pnpm admin:init --email 协会邮箱 --user-id 协会userId
```

也可用 `PF_ADMIN_EMAIL` / `PF_ADMIN_EXTERNAL_USER_ID` 环境变量。已有用户不会被命令自动提权或覆盖；原管理员用上述 `user:link`。本次没有提供真实 APPKEY 或身份 ID，因此没有猜测绑定任何现有账号。

## 权限与会话

「用户管理」只调整本系统角色、启停账号和撤销会话；名称、邮箱、密码及注册统一在协会官网管理。本地创建密码用户、修改密码、发起/消费密码重置接口已移除。旧密码重置 URL 回到登录页。

账号权限更新使用版本检查。角色或启停改变会撤销全部本地会话；本地停用用户即使协会验证成功也不能登录。至少保留一个启用且绑定了协会身份的管理员。登录身份同步/签发会话、管理员账号变更与显式绑定共用 PostgreSQL 事务锁，避免停用或权限修改与会话签发交错。

用户可以在「账户设置」查看有效会话、退出其他设备或所有设备。有效期仍为 7 天；失效会话后续请求返回 401，SSE 下一次鉴权时关闭。官网文档没有提供令牌验证/退出通知接口，官网改密、停用或退出不会主动撤销已经签发的本地会话；需要立即停止本系统访问时在此停用或撤销会话。

## 定向验证

`pnpm verify:access` 使用模拟的协会响应和**原数据库的必定回滚事务**验证实际 Fastify 路由、身份绑定、会话/权限与移除审批后的直接冻结。不开新端口、不建数据库、不发送外网请求、不执行作者代码或 TeX。默认 `test` / `test:quick` 不变。

P0—P7 的本地密码账号验证脚本属于历史验收路径，未对新登录重新验收，不能直接拿旧夹具向协会登录。真实成功登录仍须取得有效 APPKEY 和协会测试账号后联调。
