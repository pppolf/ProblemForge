\section*{交互注意事项}

每次输出询问后，都必须立即刷新标准输出缓冲区。
例如在 C++ 中可以使用：
\begin{verbatim}
cout << "? " << k << endl;
\end{verbatim}

或：
\begin{verbatim}
cout << "? " << k << '\n' << flush;
\end{verbatim}

不要读取或写入交互协议未规定的信息。
在这里说明超过询问次数、询问格式错误、答案错误的判定，以及协议规定的异常终止方式（如有）。
